# UCU Web Accessibility Project

## About this project
This repository contains my semester coursework for building and improving a basic, accessible website as part of my Foundation Studies work at Uganda Christian University. It is also where I keep my Week 2 Competency Evidence: a Git/GitHub workflow demonstration and a web accessibility audit.

## Current purpose
Right now, this repository holds:
- A starter homepage (`index.html`) built with accessible, semantic HTML.
- An accessibility audit (`docs/accessibility-audit.md`) identifying common accessibility issues on basic websites, who they affect, and how to fix them.
